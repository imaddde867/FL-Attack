Privacy Leakage in Federated Learning

CelebA · SimpleCNN, 8.76M parameters · gradient inversion attack

Overview

Federated learning is sold on one promise: raw client data never leaves the device, and only gradients get shared. That promise is weaker than it sounds. An honest-but-curious server can rebuild a recognizable face from a single client's gradient update, with no aggregation involved. The benchmark below scores reconstruction quality (how strong the attack is) with no defense and with two candidate defenses. It never scores model accuracy, so it has nothing to say about the privacy/utility tradeoff.

Threat Model & Scope

Every result below reads one client's raw gradient before any aggregation (attack_source="gradients"). Local differential privacy (clip that client's release, add calibrated Gaussian noise) is the right mechanism for exactly this release point, so that is the defense this benchmark evaluates. It is not a bug that ε=8, 1, and 0.1 all land at roughly the same PSNR: per-coordinate Gaussian noise has L2 norm scaling ~σ√d, and at this model's d≈8.76M parameters, even ε=8 already injects noise ~1800× the clipped signal bound. The figure below works through it.

The "HE" row does not test encryption. The implementation quantizes gradients and adds fixed-scale Laplace noise; at this model size it never executes real Paillier encryption, and even when it does, the code decrypts the result before scoring it. A real secure-aggregation deployment would never hand that decrypted intermediate to the attacker simulated here. The honest version of the experiment already exists in the codebase (capture_mode='agg_update' plus aggregate_clipped_noisy's central-DP mechanism, attacking only the FedAvg-averaged update), but running it needs GPU/CelebA compute that was unavailable this cycle. It stays a stated limitation on the scope of these numbers.

Robustness across clients

Across ten independently sampled clients, reconstruction quality stays in a narrow band. The leak follows from the gradient release itself, and it shows up on every participant sampled here.

Results: Defenses

Local differential privacy acts on exactly the release point this attack reads: one client's own gradient, clipped and noised before it ever leaves the device. The epsilon sweep is the centerpiece here.

Read the "HE" row with its caveat
The "HE" configuration below does not test encryption, and the central-DP / secure-aggregation release point went unmeasured. Read Threat Model & Scope before quoting either number.
